> Actúa como un Arquitecto de Software Senior y Desarrollador Full Stack 
especializado en paneles administrativos complejos. Vamos a construir un 
dashboard web para administrar este bot

**Contexto del Problema:**
Actualmente, la administración es manual y fragmentada. Para crear una 
historia bloqueada, el admin debe:
1. Ir a Tienda -> Crear Producto -> Copiar ID.
2. Ir a Narrativa -> Crear Fragmento -> Pegar ID del producto para 
bloquearlo.
3. Ir a Configuración -> Crear Trigger de recompensa -> Pegar IDs de nuevo.

**Objetivo:**
Crear un "Sistema de Administración Unificado" donde las dependencias se 
gestionen automáticamente. Si creo un fragmento bloqueado, debo poder crear 
el producto que lo bloquea *en la misma pantalla* y el sistema debe 
encargarse de crear el producto, obtener su ID y vincularlo al fragmento 
automáticamente.

sistema

● 📋 Esquema de API para Panel de Administración Unificado

  Análisis de Arquitectura Completado

  He analizado el documento y identificado las relaciones críticas que
  necesitan automatización. A continuación presento un diseño de API RESTful
   completo con soporte para Nested Creation y gestión automática de 
  dependencias.

  ---
  🏗️ Principios de Diseño

  1. Nested Creation Pattern

  Los endpoints soportan creación de entidades relacionadas en una sola
  transacción atómica.

  2. Referencia Inteligente

  Permite referenciar entidades existentes (por ID) o crear nuevas inline
  (objeto completo).

  3. Validación en Cascada

  El backend valida automáticamente integridad referencial antes de commit.

  4. Idempotencia

  Los endpoints usan IDs de negocio (keys) para evitar duplicados.

  🎯 1. MÓDULO DE NARRATIVA

  POST /api/v1/narrative/fragments

  Crea un fragmento con soporte para nested creation de productos y 
  decisiones.

  Request Body (Nested Creation):

  {
    "key": "CAP10_INTRO",
    "text": "Entraste a la habitación oscura...",
    "image_url": "https://...",
    "min_besitos": 0,
    "required_role": null,
    "reward_besitos": 10,

    // OPCIÓN 1: Referencia a producto existente
    "unlock_product_id": 42,

    // OPCIÓN 2: Crear producto al vuelo (NESTED)
    "unlock_product": {
      "name": "Acceso Capítulo 10",
      "description": "Desbloquea el capítulo completo",
      "price": 50,
      "is_vip_only": false,
      "stock_limit": null
    },

    // OPCIÓN 3: Crear múltiples decisiones inline
    "choices": [
      {
        "text": "Entrar sigilosamente",
        "destination_fragment_key": "CAP10_SIGILO",
        "required_besitos": 0
      },
      {
        "text": "Entrar con confianza",
        "destination_fragment_key": "CAP10_CONFIANZA",
        "required_besitos": 20,
        // También puede crear el destino al vuelo
        "destination_fragment": {
          "key": "CAP10_CONFIANZA",
          "text": "Entraste con paso firme..."
        }
      }
    ],

    // Auto-avance si no hay decisiones
    "auto_next_fragment_key": null
  }

  Response:

  {
    "success": true,
    "data": {
      "fragment": {
        "id": 156,
        "key": "CAP10_INTRO",
        "text": "Entraste a la habitación oscura...",
        "unlock_product_id": 87  // ID auto-generado
      },
      "created_product": {
        "id": 87,
        "name": "Acceso Capítulo 10"
      },
      "created_choices": [
        {"id": 201, "text": "Entrar sigilosamente"},
        {"id": 202, "text": "Entrar con confianza"}
      ]
    },
    "message": "Fragmento creado con 1 producto y 2 decisiones"
  }

● 📦 DTOs y Modelos (FastAPI/Pydantic)

  Modelos Base para Nested Creation

  # models/nested.py

  from pydantic import BaseModel, Field
  from typing import Optional, Union, List
  from datetime import datetime
  from enum import Enum

  # ==================== ENUMS ====================

  class RewardType(str, Enum):
      BESITOS = "besitos"
      PRODUCT = "product"
      LORE = "lore"
      VIP_DAYS = "vip_days"
      FRAGMENT_UNLOCK = "fragment_unlock"

  class TriggerEventType(str, Enum):
      FRAGMENT_VIEWED = "FRAGMENT_VIEWED"
      PRODUCT_PURCHASED = "PRODUCT_PURCHASED"
      MISSION_COMPLETED = "MISSION_COMPLETED"
      USER_CREATED = "USER_CREATED"
      POINTS_THRESHOLD = "POINTS_THRESHOLD"

  class ActionType(str, Enum):
      GIVE_PRODUCT = "GIVE_PRODUCT"
      GRANT_VIP = "GRANT_VIP"
      UNLOCK_FRAGMENT = "UNLOCK_FRAGMENT"
      ADD_POINTS = "ADD_POINTS"
      SEND_MESSAGE = "SEND_MESSAGE"
      UNLOCK_LORE = "UNLOCK_LORE"

  # ==================== NESTED MODELS ====================

  class ProductCreateNested(BaseModel):
      """Modelo para crear producto inline (nested)"""
      name: str = Field(..., min_length=1, max_length=255)
      description: Optional[str] = None
      price: int = Field(..., ge=0)
      is_vip_only: bool = False
      stock_limit: Optional[int] = Field(None, ge=1)
      max_purchases_per_user: int = Field(1, ge=1)
      available_from: Optional[datetime] = None
      available_until: Optional[datetime] = None

      class Config:
          json_schema_extra = {
              "example": {
                  "name": "Acceso Capítulo 10",
                  "description": "Desbloquea el capítulo completo",
                  "price": 50,
                  "is_vip_only": False
              }
          }

  class FragmentCreateNested(BaseModel):
      """Modelo para crear fragmento inline"""
      key: str = Field(..., min_length=1, max_length=50)
      text: str = Field(..., min_length=1)
      image_url: Optional[str] = None
      min_besitos: int = Field(0, ge=0)
      required_role: Optional[str] = None
      reward_besitos: int = Field(0, ge=0)

  class LoreCreateNested(BaseModel):
      """Modelo para crear lore inline"""
      lore_id: str = Field(..., max_length=50)
      title: str = Field(..., max_length=255)
      content: str
      is_unlocked_by_default: bool = False

  class NarrativeChoiceNested(BaseModel):
      """Decisión narrativa (puede crear destino inline)"""
      text: str = Field(..., max_length=255)
      destination_fragment_key: Optional[str] = None

  # api/routes/narrative.py

  from fastapi import APIRouter, HTTPException, Depends
  from sqlalchemy.ext.asyncio import AsyncSession
  from sqlalchemy import select
  from typing import Optional

  from database.setup import get_db
  from database.models import StoryFragment, ShopItem, NarrativeChoice
  from models.nested import FragmentCreateRequest, FragmentCreateResponse

  router = APIRouter(prefix="/api/v1/narrative", tags=["Narrative"])

  @router.post("/fragments", response_model=FragmentCreateResponse)
  async def create_fragment_with_nested(
      request: FragmentCreateRequest,
      db: AsyncSession = Depends(get_db)
  ):
      """
      Crea un fragmento con soporte para nested creation de productos y 
  decisiones.
      
      Casos soportados:
      1. Fragmento simple (sin bloqueo)
      2. Fragmento + referencia a producto existente
      3. Fragmento + creación de producto inline (NESTED)
      4. Fragmento + múltiples decisiones inline
      """

      try:
          # ===== VALIDACIÓN =====

          # Verificar que el key no exista
          existing = await db.execute(
              select(StoryFragment).where(StoryFragment.key == request.key)
          )
          if existing.scalar_one_or_none():
              raise HTTPException(
                  status_code=400,
                  detail=f"Fragment with key '{request.key}' already exists"
              )

          # ===== NESTED CREATION: PRODUCTO =====

          created_product = None
          unlock_product_id = request.unlock_product_id

          # Si se proporciona un producto nested, crearlo primero
          if request.unlock_product:
              product_data = request.unlock_product.dict()
              new_product = ShopItem(**product_data)
              db.add(new_product)
              await db.flush()  # Genera el ID sin hacer commit

              unlock_product_id = new_product.id
              created_product = {
                  "id": new_product.id,
                  "name": new_product.name,
                  "price": new_product.price
              }

          # ===== CREACIÓN DEL FRAGMENTO =====

          fragment = StoryFragment(
              key=request.key,
              text=request.text,
              image_url=request.image_url,
              min_besitos=request.min_besitos,
              required_role=request.required_role,
              reward_besitos=request.reward_besitos,
              auto_next_fragment_key=request.auto_next_fragment_key
          )

          # Vincular producto de desbloqueo si existe
          if unlock_product_id:
              # Validar que el producto exista (si es referencia)
              if not request.unlock_product:
                  product = await db.get(ShopItem, unlock_product_id)
                  if not product:
                      raise HTTPException(
                          status_code=404,
                          detail=f"Product {unlock_product_id} not found"
                      )

              # Actualizar el producto para que desbloquee este fragmento
              if created_product:
                  await db.execute(
                      update(ShopItem)
                      .where(ShopItem.id == unlock_product_id)
                      .values(unlocks_fragment_key=request.key)
                  )

          db.add(fragment)
          await db.flush()

          # ===== NESTED CREATION: DECISIONES =====

          created_choices = []
          if request.choices:
              for choice_data in request.choices:
                  # Validar que tenga destino
                  if not choice_data.destination_fragment_key and not
  choice_data.destination_fragment:
                      raise HTTPException(
                          status_code=400,
                          detail="Each choice must have 
  destination_fragment_key or destination_fragment"
                      )

                  # Si hay fragmento nested, crearlo primero
                  destination_key = choice_data.destination_fragment_key
                  if choice_data.destination_fragment:
                      dest_fragment = StoryFragment(
                          **choice_data.destination_fragment.dict()
                      )
                      db.add(dest_fragment)
                      await db.flush()
                      destination_key = dest_fragment.key

                  # Crear la decisión
                  choice = NarrativeChoice(
                      source_fragment_id=fragment.id,
                      destination_fragment_key=destination_key,
                      text=choice_data.text,
                      required_besitos=choice_data.required_besitos,
                      required_role=choice_data.required_role
                  )
                  db.add(choice)
                  await db.flush()

                  created_choices.append({
                      "id": choice.id,
                      "text": choice.text,
                      "destination": destination_key
                  })

          # ===== COMMIT ATÓMICO =====
          await db.commit()

          # Construir respuesta
          message_parts = ["Fragmento creado"]
          if created_product:
              message_parts.append(f"con 1 producto")
          if created_choices:
              message_parts.append(f"y {len(created_choices)} decisiones")

          return FragmentCreateResponse(
              success=True,
              data={
                  "fragment": {
                      "id": fragment.id,
                      "key": fragment.key,
                      "text": fragment.text[:50] + "...",
                      "unlock_product_id": unlock_product_id
                  },
                  "created_product": created_product,
                  "created_choices": created_choices
              },
              message=" ".join(message_parts)
          )

      except HTTPException:
          await db.rollback()
          raise
      except Exception as e:
          await db.rollback()
          raise HTTPException(status_code=500, detail=f"Error creating 
  fragment: {str(e)}")

      request: TriggerCreateRequest,
      db: AsyncSession = Depends(get_db)
  ):
      """
      Crea un trigger configurable que se ejecuta automáticamente.
      
      Este endpoint reemplaza la necesidad de hardcodear lógica en el 
  código.
      """

      try:
          # Validar que las entidades referenciadas existan
          if request.fragment_key:
              fragment = await db.execute(
                  select(StoryFragment).where(StoryFragment.key ==
  request.fragment_key)
              )
              if not fragment.scalar_one_or_none():
                  raise HTTPException(404, f"Fragment 
  '{request.fragment_key}' not found")

          # Crear el trigger
          trigger = AutomationTrigger(
              name=request.name,
              enabled=request.enabled,
              trigger_event_type=request.trigger_event_type.value,
              fragment_key=request.fragment_key,
              mission_id=request.mission_id,
              product_id=request.product_id,
              points_threshold=request.points_threshold,
              conditions=request.conditions.dict() if request.conditions
  else None
          )
          db.add(trigger)
          await db.flush()

          # Crear las acciones asociadas
          for action_data in request.actions:
              action = TriggerAction(
                  trigger_id=trigger.id,
                  action_type=action_data.action_type.value,
                  product_id=action_data.product_id,
                  fragment_key=action_data.fragment_key,
                  amount=action_data.amount,
                  message_template=action_data.message_template
              )
              db.add(action)

          await db.commit()

          return {
              "success": True,
              "trigger_id": trigger.id,
              "message": f"Trigger '{request.name}' creado con 
  {len(request.actions)} acciones"
          }

      except HTTPException:
          await db.rollback()
          raise
      except Exception as e:
          await db.rollback()
          raise HTTPException(500, f"Error creating trigger: {str(e)}")

              for t in triggers

      }

  # services/automation_service.py

  from sqlalchemy.ext.asyncio import AsyncSession
  from sqlalchemy import select
  from typing import Optional

  from database.models import AutomationTrigger, TriggerAction, User,
  ShopItem, InventoryItem
  from models.nested import TriggerEventType, ActionType

  class AutomationService:
      """Servicio que ejecuta triggers automáticamente"""

      def __init__(self, db: AsyncSession):
          self.db = db

      async def execute_triggers_for_event(
          self,
          event_type: TriggerEventType,
          user_id: int,
          context: dict
      ):
          """
          Ejecuta todos los triggers activos para un evento específico.
          
          Args:
              event_type: Tipo de evento (FRAGMENT_VIEWED, etc.)
              user_id: ID del usuario que disparó el evento
              context: Datos adicionales (fragment_key, product_id, etc.)
          """

          # Buscar triggers habilitados para este evento
          query = select(AutomationTrigger).where(
              AutomationTrigger.enabled == True,
              AutomationTrigger.trigger_event_type == event_type.value
          )

          # Filtrar por contexto específico
          if event_type == TriggerEventType.FRAGMENT_VIEWED:
              query = query.where(
                  AutomationTrigger.fragment_key ==
  context.get("fragment_key")
              )
          elif event_type == TriggerEventType.MISSION_COMPLETED:
              query = query.where(
                  AutomationTrigger.mission_id == context.get("mission_id")
              )

          result = await self.db.execute(query)
          triggers = result.scalars().all()

          # Ejecutar cada trigger
          for trigger in triggers:
              # Verificar condiciones
              if not await self._check_conditions(trigger, user_id):
                  continue

              # Ejecutar acciones
              await self._execute_actions(trigger, user_id)

              # Incrementar contador
              trigger.total_activations += 1
              await self.db.commit()

      async def _check_conditions(self, trigger: AutomationTrigger, user_id:
   int) -> bool:
          """Verifica si el usuario cumple las condiciones del trigger"""

          if not trigger.conditions:
              return True

          user = await self.db.get(User, user_id)
          conditions = trigger.conditions

          # Verificar rol
          if conditions.get("user_role") and user.role !=
  conditions["user_role"]:
              return False

          # Verificar puntos mínimos
          if conditions.get("min_points") and user.points <
  conditions["min_points"]:
              return False

          # Verificar first_time_only
          if conditions.get("first_time_only"):
              # Comprobar si ya se ejecutó para este usuario
              # (necesitarías una tabla de logs)
              pass

          return True

      async def _execute_actions(self, trigger: AutomationTrigger, user_id: 
  int):
          """Ejecuta todas las acciones del trigger"""

          user = await self.db.get(User, user_id)

          for action in trigger.actions:
              if action.action_type == ActionType.GIVE_PRODUCT.value:
                  await self._give_product(user_id, action.product_id)

              elif action.action_type == ActionType.ADD_POINTS.value:
                  user.points += action.amount

              elif action.action_type == ActionType.GRANT_VIP.value:
                  user.vip_expires_at = datetime.now() +
  timedelta(days=action.amount)
                  user.role = "vip"

              elif action.action_type == ActionType.UNLOCK_FRAGMENT.value:
                  # Añadir a unlocked_fragments del UserNarrativeState
                  state = await self._get_or_create_narrative_state(user_id)
                  if action.fragment_key not in state.unlocked_fragments:
                      state.unlocked_fragments.append(action.fragment_key)

              elif action.action_type == ActionType.SEND_MESSAGE.value:
                  # Encolar mensaje para envío (integración con el bot)
                  await self._send_telegram_message(
                      user_id,

  action.message_template.format(user_name=user.first_name)
                  )

          await self.db.commit()

      async def _give_product(self, user_id: int, product_id: int):
          """Añade un producto al inventario del usuario"""

          # Verificar si ya lo tiene
          existing = await self.db.execute(
              select(InventoryItem).where(
                  InventoryItem.user_id == user_id,
                  InventoryItem.product_id == product_id
              )
          )

          if not existing.scalar_one_or_none():
              inventory_item = InventoryItem(
                  user_id=user_id,
                  product_id=product_id,
                  quantity=1
              )
              self.db.add(inventory_item)

● 📊 Resumen y Arquitectura Recomendada

  Ventajas del Sistema Propuesto

  1. Eliminación de Trabajo Manual

  - ❌ Antes: Crear producto → Copiar ID → Crear fragmento → Pegar ID
  - ✅ Ahora: Un solo request crea ambos en transacción atómica

  2. Lógica de Negocio Configurable

  - ❌ Antes: Triggers hardcodeados en handlers (requiere developer +
  deploy)
  - ✅ Ahora: Admin crea triggers desde el panel sin tocar código

  3. Validación Automática

  - ✅ El backend valida integridad referencial antes del commit
  - ✅ Dropdowns con entidades existentes (no más copy-paste de IDs)
  - ✅ Transacciones atómicas (todo se crea o nada)

  4. Escalabilidad

  - ✅ Añadir nuevas misiones, recompensas o journeys sin modificar código
  - ✅ Sistema de triggers genérico extensible a nuevos eventos

  # Decorador para verificar roles
  def require_role(min_role: str):
      def decorator(func):
          async def wrapper(*args, **kwargs):
              user = get_current_user()
              if not has_permission(user.role, min_role):
                  raise HTTPException(403, "Insufficient permissions")
              return await func(*args, **kwargs)
          return wrapper
      return decorator
